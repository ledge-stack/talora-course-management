# Talora Mobile Application (Flutter)

Student-first Flutter mobile application consuming the unified Talora OpenAPI (`/api/v1`) interface.

## Prerequisites
- Flutter SDK `>=3.0.0`
- Dart SDK `>=3.0.0`

## Development
```bash
# Get Flutter dependencies
flutter pub get

# Run on emulator/device
flutter run
```

## Features
- Student authentication (OAuth 2.0 with PKCE)
- Group discovery, creation, join requests, and invitation acceptance
- In-app inbox & tagged announcements
- Assignment submissions & deadline alerts
- Student issue reporting & request tracking
