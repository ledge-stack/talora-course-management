# Contributing

Thank you for contributing. Please follow this workflow:

1. Fork the repository and create a feature branch from `main`.
2. Run the test suite and linter before committing.
3. Keep commits focused and descriptive. Use conventional commit messages when possible.
4. Open a pull request describing the change, with relevant screenshots or reproductions for UI changes.

Testing and linting locally
```bash
npm run install:all
npm test
npm run lint
```

Code style
- The repository uses Prettier for formatting. Run `npm run format` before committing.
